基础信息

  • 基础地址：http://localhost:8000（本地开发），所有业务接口前缀为 /api/v1
  • 鉴权：当前版本无鉴权，接口默认允许前端地址跨域（CORS 白名单为 FRONTEND_URL，默认 http://localhost:5173）
  • 字符编码：UTF-8

通用响应包络

除 /api/v1/chat/stream 外，业务接口统一返回：

{ "code": 0, "message": "ok", "data": {} }
  • code 为 0 表示成功；非 0 表示业务错误
  • 已知不一致：/api/v1/chat/stream 的错误体为 { "error": "..." }；/api/v1/analytics/log 的参数错误码为 10001（不在统一错误码表内）；/api/v1/kb/* 的 code 直接复用 HTTP 状态码（400/404/413）。对接时请按各接口的实际定义处理。

统一错误码

code 含义
40001 参数校验失败
40002 上传文件缺失或类型不合法
40003 上传文件超出体积上限
50000 未预期的服务端异常
50001 语音识别服务不可用
50002 语音合成服务不可用

SSE（Server-Sent Events）约定

流式接口的响应类型均为 text/event-stream，格式为：

event: <事件名>
data: <JSON 负载>

各流式接口的事件名与负载见对应接口说明。心跳保活为注释行（以 : 开头），客户端应忽略。

  • 语音合成支持断线续传：通过 lastSeq 查询参数跳过已收到的音频分片

智能问答

基于大模型的流式对话（DashScope）

流式对话（SSE）

向大模型发起流式对话，逐 token 推送生成结果。

入参二选一：

  • 单轮：{ "message": "..." }（服务端自动补充景区导览 system 提示词）
  • 多轮：{ "messages": [{ "role": "system|user|assistant", "content": "..." }] }

SSE 事件：

event data 说明
token { "content": "增量文本" } 逐段返回的生成内容，需拼接；每条事件另带 id: <序号>（自 0 递增）
done { "fullContent": "完整回答" } 生成正常结束，另带 id: <序号>
error { "message": "错误原因" } 生成异常结束，其后仍会补发 done，**此时 done 的负载为空对象 {}**（而非 { "fullContent" }）

心跳为注释行（以 : 开头，: heartbeat，每 25 秒一次），客户端应忽略。

实时统计数据推送（SSE）

建立长连接后先下发 connected 确认帧，随即立即推送一次当前统计，此后由服务端每 5 秒广播一次。

SSE 事件：

event data 说明
connected { "id": "uuid" } 建连确认帧，id 为服务端为本次连接生成的客户端标识（randomUUID()），先于所有 stats 下发
stats AnalyticsStats 统计数据快照，结构同 GET /api/v1/analytics/stats 的 data

心跳为注释行（以 : 开头，内容形如 : heartbeat <ISO 时间>，每 15 秒一次），客户端应忽略。 客户端断开后由服务端自动清理，无需额外调用。

Responses

本地开发环境

http://localhost:8000/api/v1/analytics/stream

Response samples

  • 200
Content type
text/event-stream
event: connected
data: {"id":"3f2b9c1a-7d4e-4b8f-9a10-5c6d7e8f9012"}

event: stats
data: {"totalVisits":12,"todayVisits":3,"sentimentDist":{"positive":7,"neutral":4,"negative":1}}

: heartbeat 2026-10-20T09:15:00.000Z

event: stats
data: {"totalVisits":13,"todayVisits":4,"sentimentDist":{"positive":8,"neutral":4,"negative":1}}

语音合成（SSE 流式返回音频分片）

将文本合成为语音，以 SSE 流式推送音频分片（Base64 编码）。

text 通过查询参数传入（因 EventSource 只支持 GET，无法携带请求体），长度上限 500 字符。

断线续传：携带 lastSeq 可跳过序号小于等于该值的分片，实现重连后继续播放。

SSE 事件：

event data 说明
meta { "streamId", "text", ...音色/采样率等元信息 } 流开始，先于所有音频分片下发
audio { "seq": 1, "chunk": "<base64>", "byteLength": 8192 } 音频分片，带 id 字段（等于 seq）用于续传
done { "streamId", "totalChunks", "provider" } 合成正常结束
error { "code": 50002, "message": "..." } 合成异常结束
query Parameters
text
required
string <= 500 characters

待合成文本，长度不超过 500 字符

lastSeq
integer >= 0
Default: 0

断线续传起点，跳过序号 ≤ 该值的音频分片，缺省为 0

订阅入库进度（SSE）

订阅指定任务的入库进度，连接建立后立即推送一帧当前状态，此后状态变化即推送，直至 done 或 failed 后服务端主动关闭连接。

心跳：每 15 秒发送一次注释行（以 : 开头），客户端应忽略。

SSE 事件：

event data 说明
progress KbProgressEvent 进度快照，percent 为整体百分比（0-100）

阶段与百分比对应关系：uploading 2% → parsing 30% → chunking 50% → embedding 80% → indexing 95% → done 100%。

taskId
required
string <uuid>

入库任务标识，由上传接口或重建索引接口返回

知识库语义检索

按语义相似度检索知识块，返回 Top-K 命中结果，供对话链路的 RAG 复用，也可用于人工自检。

当前检索质量提示：若未配置 EMBEDDING_API_URL，服务端使用「本地确定性伪向量」兜底实现，此时 score 不具备语义意义；同时默认分块策略对小文件会产出极少的知识块（整篇可能只有 1 块），导致不同 query 命中同一段文本。需接入真实向量模型后检索质量才可评估。
